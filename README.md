# Gruhswad Admin Desktop

Independent local-first kitchen operations app for Gruhswad. It records orders, payments and expenses, produces cash-basis reports, imports structured WhatsApp Business orders, and publishes the existing one-day menu contract without modifying the Gruhswad web repository.

## Local development

1. Install Node 22 and pnpm 10.
2. Run `pnpm install`.
3. Run `pnpm dev`.
4. Enter the webhook URL, inbox token and dedicated Neon publication URL under **Settings**. Secrets are encrypted with the operating system account.

The SQLite database is created in Electron's per-user application-data directory. The bundled master-menu snapshot is used only to seed an empty database; subsequent reads come from SQLite.

## Neon permissions

Use separate least-privilege roles. The desktop publication role needs `SELECT`, `INSERT`, and `UPDATE` only on `menu_publications`. The webhook role needs `SELECT`, `INSERT`, `UPDATE`, and `DELETE` only on `whatsapp_inbox`. Run `webhook/schema.sql` once with a migration owner.

## WhatsApp webhook

Deploy the `webhook` directory to Vercel and configure the variables in `webhook/.env.example`. Register `/api/webhooks/whatsapp` as the Meta callback URL. Configure the desktop with the deployment base URL and the matching `INBOX_API_TOKEN`.

Only the structured message generated by the Gruhswad order page is converted into a draft order. Other messages remain marked `unmatched` for manual handling.

## Backups and reports

Backups are encrypted with Electron `safeStorage`, making them intentionally tied to the same operating-system account. Reports export to CSV for the selected date range. Restored databases are validated and applied on the next launch.

## Releases

Replace the GitHub owner in `package.json`, add signing and Apple notarization secrets documented in `.github/workflows/release.yml`, then push a `v*` tag. GitHub Actions builds signed Windows and macOS artifacts and publishes the update metadata consumed by `electron-updater`.

## Commands

- `pnpm dev` — Electron development mode
- `pnpm test` — contract and domain tests
- `pnpm typecheck` — strict TypeScript checks
- `pnpm build` — production bundles
- `pnpm dist` — local installer build
